# Kreko Mobile App

Aplicación móvil orientada a tenderos para la gestión integral de inventario, ventas, flujo de caja y evaluación de crédito alternativo (Kreko Score).

## Requisitos de Entorno
- Flutter SDK >= 3.19.0 / Dart SDK >= 3.3.0
- Android Studio / VS Code con extensiones recomendadas
- Git >= 2.40.0

## Pasos de Instalación y Ejecución Local
1. Clonar el repositorio: `git clone https://github.com/<usuario>/kreko-mobile-app.git`
2. Cambiar a la rama de desarrollo: `git checkout develop`
3. Obtener dependencias: `flutter pub get`
4. Ejecutar linter y pruebas: `flutter analyze && flutter test`
5. Iniciar la aplicación: `flutter run`
